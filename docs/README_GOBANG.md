# 3D五子棋游戏 (Gobang Game)

这是一个具有3D视觉效果的五子棋游戏，使用Python的Pygame库开发。

## 功能特性

- 经典五子棋游戏规则
- 3D视觉效果的棋子（带阴影和高光）
- 棋盘网格和星位标记
- 最后一步位置标记
- 游戏状态显示（当前玩家、胜负信息）
- 重新开始游戏功能

## 运行要求

- Python 3.x
- Pygame库
- NumPy库

## 安装依赖

```bash
pip install pygame numpy
```

## 如何运行

```bash
python gobang_game.py
```

## 游戏操作

- 使用鼠标点击棋盘下棋
- 黑棋先行
- 五子连成一线获胜
- 游戏结束后按 R 键重新开始

## 3D效果实现

- 棋子带有阴影效果，模拟立体感
- 棋子顶部有高光效果
- 棋盘使用传统颜色
- 最后一步用红色圆圈标记
